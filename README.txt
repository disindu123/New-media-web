- styles.css

- assets/logo-banner.png
- assets/facebook-reference.png

Quick setup:
1. Open index.html in a browser.
2. Replace the social links in index.html.
3. Replace INQUIRY_EMAIL in script.js with the Media Unit's real email address.
4. Replace the placeholder team names and any copy with the real committee details.
5. Upload the whole folder to your hosting provider.

Design direction:
- White base with Sanghabodhi navy + blue + yellow theme.
- Animated ticker, floating elements, scroll reveal, hover tilt, responsive mobile menu.
- Contact / enquiry area is styled like the supplied reference image.
